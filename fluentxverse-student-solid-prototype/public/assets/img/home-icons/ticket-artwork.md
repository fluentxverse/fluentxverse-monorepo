# Ticket Artwork

Generated using the built-in image generation tool. Original generated PNGs remain in the Codex generated_images directory. Project assets are transparent WebP derivatives.

- basic-ticket-v1.webp: Cobalt blue and mint lesson admission ticket, soft premium 3D illustration, rounded bevels, paper perforation, semicircular notches, embossed graduation-cap symbol. Three-quarter view, centered, readable at 48px. Transparent background, no text or watermark.
- premium-ticket-v1.webp: Gold lesson admission ticket, satin gold face, cobalt blue beveled edge, embossed blue star medallion, paper perforation, semicircular notches. Matching soft premium 3D illustration, three-quarter view, centered, readable at 48px. Transparent background, no text or watermark.

Palette and rendering match the existing Home illustrations. Basic and Premium are labeled in HTML rather than in the images.

## Version 2

Replaced the intricate ticket imagery with a matched pair using the built-in image generation tool. Both are lossless transparent PNG files on identical 640 x 360 canvases. PNG preserves clean edges; the local WebP conversion introduced visible transparency artifacts.

- basic-ticket-v2.png prompt: Front-facing horizontal admission ticket, gentle 8 degree counterclockwise tilt, width twice height. Cobalt-blue border, mint inset, one large simple graduation-cap emblem. Smooth soft 3D bevels, clean antialiased edges, strong silhouette, minimal details, no lettering or perforation dashes. Centered, 90% width, clean transparency, no text or watermark.
- premium-ticket-v2.png edit prompt: Preserve the reference Basic ticket's exact silhouette, proportions, tilt, framing, position, blue beveled border, notch shape, transparency and lighting. Change only the mint face to warm satin gold and replace the cap with one large simple blue five-point star. No extra details, text or ornamentation.

Home renders both at 64 x 40 with contain sizing; Browse Tutors uses matching 48 x 30 frames.
