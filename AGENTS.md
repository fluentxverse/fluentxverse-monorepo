# Lesson Authoring

- Write and revise lesson content directly in the coding conversation.
- Do not call external model APIs for lesson drafting, simplification, review,
  translation checks, or model-availability probes. Do not use the application's
  API keys for these tasks. The owner reserves those credits for Daily Dispatch.
- Do not recreate an API-backed lesson batch generator or switch to another
  provider to bypass this rule. Changing this policy requires an explicit new
  instruction from the owner.
- Offline compilers, unit tests, read-only browser verification, and guarded
  Memgraph content persistence are allowed. Do not alter credentials or disable
  existing application features as a side effect of authoring work.
- Preserve lesson identities, artwork, publication states, fixed feedback,
  student notes, exercise marks, and saved personalized checkpoints.
