# Homepage Web3 Ecosystem

The homepage identifies technology usage, not sponsorship or commercial
partnerships. Arbitrum is the leading network; zkVerify handles proof verification
and Robinhood Chain hosts the tutor reward contracts. Alchemy supplies RPC/pricing,
Privy supports student sign-in, OpenZeppelin supplies contract libraries and Aero
provides reward swaps. Descriptions do not promise paid rewards or an audit.
